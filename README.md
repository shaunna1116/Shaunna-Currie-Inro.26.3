## Art Gallery

This project uses the Art Institute of Chicago API to display artwork in an interactive gallery.

### How to Use

1. Open the Art Gallery page from my portfolio.
2. Browse six artwork titles at a time.
3. Use the Previous and Next buttons to move through the list of artwork titles.
4. Click an artwork title to view the artwork image and title.
5. Click the Details button to view information about the selected artwork.
6. Use the Back to Portfolio link to return to the portfolio.

### API

This project uses the Art Institute of Chicago API.

API Documentation: https://api.artic.edu/docs/

The first GET request retrieves a list of 36 artworks with their IDs, titles, and image IDs.

The second GET request retrieves detailed information about the selected artwork when the user clicks the Details button. This includes the artist, date, medium, dimensions, and description.

No API key is required.
